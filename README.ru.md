# ⚓ E4K Fleet Optimizer

Специализированная десктопная утилита для **[Empire: Four Kingdoms](https://play.google.com/store/apps/details?id=air.com.goodgamestudios.empirefourkingdoms)**. Этот инструмент полностью устраняет необходимость ручных математических расчетов, автоматически вычисляя наиболее эффективные комбинации кораблей для слотов вашего флота, обеспечивая максимальную вместимость и оптимизированные характеристики.

## ✨ Возможности
* **Автоматический расчет флота:** Мгновенно рассчитывает лучшее распределение кораблей для достижения максимальной прибыли и эффективности.
* **Умная оптимизация слотов:** Точно размещает корабли в доступные слоты на основе их индивидуальных характеристик и грузоподъемности.
* **Современный интерфейс:** Элегантный, полностью оптимизированный пользовательский интерфейс, поддерживающий как **Темную, так и Светлую темы**, созданный для вашего комфорта.
* **Автономная обработка:** Быстрая локальная обработка данных, выполняющая все сложные вычисления непосредственно на вашем компьютере.

## 🏗 Архитектура и паттерны
Проект построен на принципах чистого кода, что обеспечивает высокую поддерживаемость и масштабируемость:
* **Паттерн MVVM:** Использует `CommunityToolkit.Mvvm` для строгого разделения пользовательского интерфейса (Views) и бизнес-логики (ViewModels).
* **Внедрение зависимостей (DI):** Использует `Microsoft.Extensions.DependencyInjection` для слабой связности, регистрации сервисов, поставщиков данных и ViewModels через централизованный IoC-контейнер.
* **Элементы Domain-Driven Design (DDD):** Архитектура разделена на независимые слои (`Core` и `WPF`). Бизнес-логика и доменные модели (`OptimizationResult`, иммутабельные сущности `record`) полностью изолированы от UI и реализаций доступа к данным.
* **Паттерн Provider:** Получение данных абстрагировано через интерфейсы (`IShipDataProvider`, `IShipReferenceProvider`), что позволяет беспрепятственно переключаться между реализациями JSON, CSV или будущими базами данных.

## 🗺️ Планы на будущее
Проект активно развивается. Вот запланированные функции для следующих релизов:
* **Отслеживание карты в реальном времени:** Интеграция фонового сетевого анализатора для автоматического обнаружения и сохранения координат фортов и свободных островов.
* **Многоязычная поддержка (Локализация):** Полный перевод интерфейса на несколько языков (английский, украинский, русский) для поддержки более широкой глобальной базы игроков.
* **Переход на веб-архитектуру:** Перенос ядра оптимизации с локального десктопного приложения на full-stack веб-приложение с независимым бэкендом API и фронтендом.

## 🚀 Установка и использование

**Для игроков:**
1. Перейдите на страницу [Releases](../../releases/latest).
2. Скачайте последний файл `E4KFleetOptimizer_Setup.exe`.
3. Запустите установщик и откройте программу. 
   *(Примечание: Программа требует установленной среды [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/8.0). Установщик должен обработать зависимости автоматически, но вы можете скачать его вручную, если появится соответствующий запрос).*

**Для разработчиков:**
1. Клонируйте репозиторий: 
   ```bash
   git clone [https://github.com/Tokar08/E4KFleetOptimizer.git](https://github.com/Tokar08/E4KFleetOptimizer.git)
   ```
2. Откройте `E4KFleetOptimizer.sln` в Visual Studio 2022 или новее.
3. Visual Studio автоматически восстановит необходимые NuGet пакеты. Если используете CLI, выполните:
   ```bash
   dotnet restore
   ```
4. Соберите и запустите проект в режиме `Release` или `Debug`.
